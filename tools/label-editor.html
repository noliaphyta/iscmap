Room label editor

Fixes and additions to OCR-detected room-number points (see tools/ocr_ingest.py) - polygons are not used right now.

1. Pick a floorplan and load it - any labels already in data/floorN.json (accepted and flagged) load automatically.
2. Click the map to add a new point, click an existing point to select/edit/move/delete it, or resolve a flagged (amber) point from the list.
3. Copy the JSON below into data/floorN.json's "labels" key, or use "Download floor JSON" for the whole file at once (preserves every other key already in the file).

In "Click to add" mode, clicking empty map space drops a new point at that spot and selects it below for you to fill in. Clicking an existing point always selects it, in either mode.

Must match ^\d{4}[A-Z]?$ - exactly four digits, then an optional single letter.

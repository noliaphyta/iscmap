Floor plan polygon editor

1. Pick a floorplan and load it — dimensions, floor number, and any already-saved rooms/features are all picked up automatically.
2. Trace room outlines or drop point-feature icons. Click a saved room to edit it in place (drag its points, splice in a fix, or merge it with another room).
3. Copy the JSON below into data/floorN.json, or use "Download floor JSON" for the whole file at once.

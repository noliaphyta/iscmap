Floor plan polygon editor

1. Paste an image URL/path (or a local file) and load it.
2. Pick a mode below: trace room outlines, or drop point-feature icons (exits, elevators, restrooms, etc).
3. When done, copy each JSON block into the matching array in data/<building>/floorN.json (rooms and features are separate arrays in the same file).

Points traced: 0 (click "Save room" when the outline is closed)
